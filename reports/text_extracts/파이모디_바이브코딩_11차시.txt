유선 vs 무선 비교
항목 US B 유선 Bluetooth 무선 Wi - Fi 무선
연결 방식 US B 케이블 Bluetooth 페어링 Wi - Fi 네트워크
거리 ~ 2m (케이블 길이) ~ 10m ~ 50m (실내)
속도 빠름 보통 빠름
장점 안정적, 전원 공급 간편, 1:1 연결 여러 기기 연결
단점 이동 제한 거리 제한 설정 복잡
활용 초기 테스트 로봇, 자동차 제어 원격 모니터링
무선이 필요한 상황
• 로봇/자동차를 원격으로 조종할 때 (케이블이 있으면 움직일 수 없음!)
• 센서값을 멀리서 모니터링할 때
• 여러 파이모디를 동시에 제어할 때

1 N etwork 모듈 전원 ON US B 분리 후 배터리/외부 전원 연결
2 BLE 모드 확인 N etwork 모듈 LED 가 파란색으로 깜빡이면 BLE 대기 상태
3 컴퓨터 블루투스 ON 설정 → Bluetooth → 켜기
4 p ym od i 코드에서 연결 M O D IPlus(co nnectio n_typ e = "b le")로 BLE 연결
5 연결 확인 b und le.m od ules 로 모듈 목록 출력

실습 — 무선으로 LED 원격 제어
BLE로 연결한 파이모디의 LED를 원격으로 제어합니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 03
실습 A: 무선 LED 켜기/끄기
import modi_plus, time
# BLE 무선 연결
bundle = modi_plus.MODIPlus(connection_type="ble", network_uuid="E276737")
led = bundle.leds[0]
display = bundle.displays[0]
print("무선 연결 성공!")
display.text = "WIRELESS!"
led.rgb = (0, 255, 0)
time.sleep(3)
led.turn_off()
display.clear()
실습 B: 무선 리모컨 (input 명령)
import modi_plus, time
bundle = modi_plus.MODIPlus(connection_type="ble",
network_uuid="E276737")
led = bundle.leds[0]
display = bundle.displays[0]
while True:
cmd = input("명령(r/g/b/off/q): ")
if cmd == "r":
led.rgb = (255,0,0)
display.text = "RED"
elif cmd == "g":
led.rgb = (0,255,0)
display.text = "GREEN"
elif cmd == "b":
led.rgb = (0,0,255)
display.text = "BLUE"
elif cmd == "off":
led.turn_off()
display.text = "OFF"
elif cmd == "q":
break

창고 보안 ToF·소리 침입 감지 시 LED 경보
식물 관리 온도·습도·빛 화분 옆에 놓고 원격 관찰
로봇 자동차 ToF· IM U 장애물 감지 + 기울기 확인
무선 센서 읽기 코드
import modi_plus, time
bundle = modi_plus.MODIPlus(connection_type="ble", network_uuid="E276737")
env = bundle.envs[0]
display = bundle.displays[0]
led = bundle.leds[0]
while True:
t = env.temperature
h = env.humidity
print(f"온도:{t:.1f}C 습도:{h:.0f}%")
display.text = f"T:{t:.1f} H:{h:.0f}"
if t > 30: led.rgb = (255,0,0)
else: led.rgb = (0,255,0)
time.sleep(2)

실습 — 무선 원격 환경 감시 + 바이브코딩도전
무선으로 센서값을 읽고, 조건에 따라 LED· Display를 자동 제어합니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 05
실습 A: 무선 스마트 알림 시스템
import modi_plus, time
bundle = modi_plus.MODIPlus(connection_type="ble", network_uuid="E276737")
env = bundle.envs[0]
led = bundle.leds[0]
display = bundle.displays[0]
while True:
t = env.temperature
s_ = env.volume
if t > 30 and s_ > 50:
led.rgb = (255,0,0)
display.text = "ALERT!"
elif t > 30:
led.rgb = (255,255,0)
display.text = f"HOT:{t:.0f}C"
else:
led.rgb = (0,255,0)
display.text = "OK"
time.sleep(1)

출력하고, 온도가 28도 넘으면 LED 빨간색 + Display에 경고 메시지 표시하는 코드 만들

줘. 모드1: 온도 표시, 모드2: 습도 표시, 모드3: 조도 표시. Display에 현재 모드명과 값을
