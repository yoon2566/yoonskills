주석(Comment) — 코드에 메모 남기기
주석은 실행되지 않는 설명문으로, 코드를 이해하기 쉽게 도와줍니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 01
주석이란?
주석(Comment)은 코드에 적는 메모입니다. 파이썬이 실행할 때 완전히
무시하기 때문에 프로그램에 영향을 주지 않습니다.
왜 필요한가?
• 나중에 코드를 다시 봤을 때 이해하기 위해
• 다른 사람이 내 코드를 읽을 때 설명해주기 위해
• 바이브코딩에서 AI가 만든 코드를 내가 이해하기 위해
• 일시적으로 코드를 비활성화(주석 처리)하기 위해
주석 작성법
종류 문법 설명
한 줄 주석 # 뒤에 설명 # 이후 줄 끝까지 무시
인라인 주석 코드 # 설명 코드 옆에 짧은 설명
여러 줄 주석 """설명""" 삼중 따옴표로 여러 줄
주석 처리 # 코드 코드를 임시로 비활성화
# 이것은 한 줄 주석입니다
name = "Alice" # 인라인 주석
"""
여러 줄 주석:
이 부분은 모두 무시됩니다
설명이 길 때 사용합니다
"""
age = 17
# print(age) ← 주석 처리 (실행 안 됨)
print(name) # Alice 출력됨
※ 바이브코딩 팁: AI가 생성한 코드에 주석이 있으면 반드시 읽어보세요.
주석이 코드의 동작을 설명해줍니다!

변수와 자료형 — 값을 저장하는 이름표
변수(variable)는 값을 담는 상자, 자료형(type)은 상자 안에 들어가는 값의 종류입니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 03
변수란?
변수는 값을 저장하는 이름표입니다.
age = 17 → age라는 이름표에 17을 저장
변수 규칙:
• 영문·숫자· _ 조합 (한글도 가능하지만 비추천)
• 숫자로 시작 불가 (1age
 , age1
 )
• 대소문자 구분 (Name ≠ name)
• 예약어 사용 불가 (if, for, while 등)
4가지 자료형
자료형 설명 예시
int 정수 (소수점 없는 숫자) 17, - 3, 100
float 실수 (소수점 있는 숫자) 1.5, 3.14
str 문자열 (따옴표로 감싼 글자) "A lice"
b ool 논리값 (참/거짓) True, False
age = 17 # int (정수)
height = 175.5 # float (실수)
name = "Alice" # str (문자열)
is_ok = True # bool (논리값)
print(type(age)) # <class 'int'>
print(type(name)) # <class 'str'>
※ type() 함수로 자료형 확인 가능. 형변환: int(), float(), str(), bool()

# 실습 A: 내 정보를 변수에 저장
name = "홍길동" # str

실습 B: 형변환 실험

연산자 — 계산하고 비교하고 판단하기
산술·비교·논리 연산자를 배워 계산과 조건 판단을 할 수 있습니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 05
산술 연산자
연산자 의미 예시 결과
+ - * 더하기 빼기 곱하기 10+ 3, 10 - 3, 10*3 13, 7, 30
/ 나누기 (실수) 10 / 3 3.333...
// 몫 (정수 나누기) 10 // 3 3
% 나머지 10 % 3 1
** 거듭제곱 2 ** 10 1024
비교·논리 연산자
연산자 의미 예시 → 결과
= = ! = 같다 / 다르다 5= = 5→True, 5!= 3→True
> < > = < = 크기 비교 5> 3→True, 3> = 5→False
and 둘 다 참 True and True→True
or 하나만 참 True or False→True
not 반대 not True→False
a, b = 10, 3
print(a + b) # 13
print(a // b) # 3 (몫)
print(a % b) # 1 (나머지)
print(5 == 5) # True
※ "=" 는 대입(값 넣기), "==" 는 비교(같은지 확인) — 절대 헷갈리지 마세요!

input으로 입출력 — 사용자에게값 받기
input() 함수로 키보드 입력을 받고, 형변환으로 숫자로 바꿉니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 09
input() 동작 원리
input()은 사용자에게 값을 입력받는 함수입니다.
① 화면에 질문 표시 → ② 사용자가 타이핑 후 Enter → ③ 변수에 저장
주의: input()의 결과는 항상 문자열(str)!
숫자로 쓰려면 int() 또는 float()로 형변환 필수!
# 기본 사용법
name = input("이름: ") # 문자열
age = int(input("나이: ")) # 정수 변환
h = float(input("키(cm): ")) # 실수 변환
print(f"안녕, {name}! {age}살, {h}cm!")
input 핵심 정리
용도 코드 결과 타입
문자열 입력 inp ut(" 이름: ") str
정수 입력 int(inp ut(" 나이: ")) int
실수 입력 float(inp ut(" 키: ")) float
# 형변환 안 하면?
age = input("나이: ") # "17" (문자열!)
print(age + 1) # TypeError 오류!
# 올바른 방법
age = int(input("나이: ")) # 17 (정수)
print(age + 1) # 18 (정상!)
※ input()은 항상 str을 반환! 숫자 계산을 하려면 반드시 int() 또는 float()로 감싸야 합니다.

# 실습 A: 태어난 해 계산기
name = input("이름: ")

실습 B: BMI 계산기
# 실습 B: BMI 계산기
# BMI = 몸무게(kg) / 키(m)^2
h_cm = float(input("키(cm): "))
w = float(input("몸무게(kg): "))
h_m = h_cm / 100 # cm → m 변환
bmi = w / (h_m ** 2)
print(f"\nBMI: {bmi:.1f}")
if bmi < 18.5:
print("저체중")
elif bmi < 25:
print("정상")
else:
print("과체중")
