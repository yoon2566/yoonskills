실습 — 날씨 데이터 가져오기 + JSON 읽기
requests로 API를 호출하고 JSON 데이터를 파싱합니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 03
실습 A: 날씨 가져오기
import requests
API_KEY = "YOUR_API_KEY"
city = "Seoul"
url = (f"http://api.openweathermap.org"
f"/data/2.5/weather?q={city}"
f"&appid={API_KEY}"
f"&units=metric&lang=kr")
res = requests.get(url)
data = res.json()
temp = data["main"]["temp"]
desc = data["weather"][0]["description"]
humi = data["main"]["humidity"]
print(f"서울 날씨: {desc}")
print(f"온도: {temp}C, 습도: {humi}%")
