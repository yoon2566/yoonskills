복합 조건 — 여러 센서를 동시에 판단하기
and/or 논리 연산자로 2개 이상 센서를 동시에 확인합니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 01
and / or / not 정리
연산자 의미 예시 결과
and 둘 다 참이어야 True 빛< 30 and 소리> 50 둘 다 맞아야 실행
or 하나만 참이면 True 온도> 35 or 습도> 80 하나만 맞아도 실행
not 반대로 뒤집기 not b utton.clicked True→False 변환
복합 조건 코드 예시
# 어둡고 시끄러우면 = 긴급!
if env.illuminance < 30 and env.volume > 50:
led.rgb = (255, 0, 0)
display.text = "ALERT!"
elif env.illuminance < 30: # 어둡기만 하면
led.rgb = (255, 255, 0)
display.text = "DARK"
else: # 그 외
led.turn_off()
display.text = "OK"
핵심 원칙: 우선순위 순서
조건 순서가 중요합니다!
가장 긴급한 조건(and)을 먼저 검사하고, 덜 긴급한 조건(elif)을 나중
에 검사합니다.
만약 elif를 if 앞으로 옮기면?
→ "어두움"만 체크되고
→ "어둡고 시끄러운" 긴급 상황을 놓칩니다!

실습 A: 불쾌지수 알림
import modi_plus, time
bundle = modi_plus.MODIPlus()
env = bundle.envs[0]
led = bundle.leds[0]
display = bundle.displays[0]
while True:
t = env.temperature
h = env.humidity
# 불쾌: 고온 AND 고습
if t > 28 and h > 70:
led.rgb = (255, 0, 0)
display.text = "UNCOMFORT!"
elif t > 28 or h > 70:
led.rgb = (255, 255, 0)
display.text = f"T:{t:.0f} H:{h:.0f}"
else:
led.rgb = (0, 255, 0)
display.text = "COMFORT"
time.sleep(1)
실습 B: 스마트 야간 모드
import modi_plus, time
bundle = modi_plus.MODIPlus()
env = bundle.envs[0]
button = bundle.buttons[0]
led = bundle.leds[0]
display = bundle.displays[0]
night_mode = False
while True:
if button.clicked:
night_mode = not night_mode
light = env.illuminance
if night_mode and light < 30:
led.rgb = (50, 50, 20)
display.text = "NIGHT ON"
elif not night_mode:
led.turn_off()
display.text = "DAY MODE"
else:
led.turn_off()
display.text = "BRIGHT"
time.sleep(0.2)

10 차시 · 다중 센서 조합
실습 — 5단계 스마트 경보 시스템 전체 코드
바이브코딩으로 생성된 경보 시스템 코드를 읽고 이해합니다
C odeW ithCathy AI 바이브코딩 × 파이모디 플러스 04
전체 코드 (왼쪽: 설정 + 함수, 오른쪽: 메인 루프)
import modi_plus, time
bundle = modi_plus.MODIPlus()
env = bundle.envs[0]
led = bundle.leds[0]
display = bundle.displays[0]
def blink(color, n=3):
for _ in range(n):
led.rgb = color
time.sleep(0.2)
led.turn_off()
time.sleep(0.2)
while True:
li = env.illuminance
so = env.volume
te = env.temperature
if li < 30 and so > 50:
blink((255,0,0))
display.text = "EMERGENCY!"
elif te > 35:
led.rgb = (255,0,0)
display.text = f"HOT!{te:.0f}C"
elif li < 30:
led.rgb = (255,255,0)
display.text = "DARK"
elif so > 50:
blink((0,0,255))
display.text = "LOUD"
else:
led.rgb = (0,255,0)
display.text = "ALL OK"
time.sleep(0.5)
• blink() 함수: LED 깜빡임을 재사용 가능하게 분리
• if→elif→else: 우선순위 순서로 체크 (긴급한 것 먼저!)
• f-string으로 온도값 동적 표시

도전 과제 1: 스마트 교실
바이브코딩 프롬프트
"파이모디 환경 센서로 스마트 교실 시스템을 만들어줘.
• 온도 28도 초과 AND 습도 70% 초과 → LED 빨강 + Display 'VENTILATE!' (환기 필요)
• 소리 60% 초과 → LED 파랑 깜빡 + Display 'QUIET!'
• 빛 20% 이하 → LED 노랑 + Display 'LIGHTS ON'
• 기본 → LED 초록 + Display 'CLASS OK'. blink 함수 사용해줘"
도전 과제 2: 주차 보조 시스템
바이브코딩 프롬프트
"파이모디 ToF 센서와 환경 센서를 조합한 주차 보조 시스템을 만들어줘.
• 거리 5cm 미만 → LED 빨강 깜빡 + Display 'STOP!' + 스피커 경고음
• 거리 15cm 미만 → LED 노랑 + Display에 거리 표시
• 거리 30cm 미만 → LED 초록 + Display에 거리 표시
• 기본 → LED 끄기 + Display RESET'. 0.2초마다 체크해줘"
※ 매핑표를 먼저 설계 → 표 내용을 그대로 프롬프트에 → AI가 정확한 코드 생성! 한 기능씩 테스트하세요!
