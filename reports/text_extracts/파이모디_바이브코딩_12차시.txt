모터 제어 명령어
명령어 설명 범위 예시
.sp eed 회전 속도 설정 - 100 ~ 100 m otor.sp eed = 50
.ang le 목표 각도로 회전 0 ~ 360 m otor.ang le = 90
양수/음수 회전 방향 결정 + 정회전 - 역회전 m otor.sp eed = - 50
0 정지 속도 0 = 멈춤 m otor.sp eed = 0
모터 기본 코드
import modi_plus, time
bundle = modi_plus.MODIPlus()
motor = bundle.motors[0]
motor.speed = 50 # 정회전 50%
time.sleep(2)
motor.speed = -50 # 역회전 50%
time.sleep(2)
motor.speed = 0 # 정지
자동차 구성 (모터 2개)
자동차는 왼쪽·오른쪽 모터 2개를 사용합니다.
• 둘 다 전진 → 직진
• 왼쪽만 전진 → 우회전
• 오른쪽만 전진 → 좌회전
• 둘 다 역방향 → 후진
• 둘 다 정지 → 멈춤

키보드 입력 구조
pynput은 키보드 이벤트를 감지하는 라이브러리입니다.
• on_press: 키를 누를 때 호출되는 함수
• on_release: 키를 뗄 때 호출되는 함수
• Listener: 키 이벤트를 감지하는 리스너

키보드 자동차 전체 코드
pynput으로 WASD 키 입력을 감지하고, 모터 2개를 제어하는 전체 코드입니다
C odeW ithCathy AI 바이브코딩 × 파이모디 플러스 04
import modi_plus
from pynput import keyboard
bundle = modi_plus.MODIPlus()
m_l = bundle.motors[0] # 왼쪽
m_r = bundle.motors[1] # 오른쪽
led = bundle.leds[0]
display = bundle.displays[0]
SPD = 60 # 기본 속도
def go(l, r, msg, color):
m_l.speed = l
m_r.speed = r
display.text = msg
led.rgb = color
def stop():
go(0, 0, "STOP", (0,0,0))
def on_press(key):
try:
k = key.char
if k == "w":
go(SPD, SPD, "FORWARD", (0,255,0))
elif k == "s":
go(-SPD, -SPD, "BACK", (255,0,0))
elif k == "a":
go(0, SPD, "LEFT", (0,0,255))
elif k == "d":
go(SPD, 0, "RIGHT", (255,255,0))
elif k == "q":
stop()
return False # 종료
except: pass
def on_release(key):
stop() # 키 떼면 정지
print("WASD=이동 Q=종료")
with keyboard.Listener(
on_press=on_press,
on_release=on_release
) as listener:
listener.join()
