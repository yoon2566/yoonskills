밝기→파이모디 연동 + 움직임 감지
카메라 밝기로 LED를 자동 제어하고, 움직임도 감지합니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 03
밝기→LED 매핑
밝기 상태 LED D isplay
0~ 80 어두움
 노란색 (255,255,0) D A RK
80~ 170 보통
 초록색 (0,128,0) N O RM A L
170~ 255 밝음
 LED O FF BRIG H T
밝기→파이모디 코드
import cv2, numpy as np, modi_plus
bundle = modi_plus.MODIPlus()
led = bundle.leds[0]
display = bundle.displays[0]
cap = cv2.VideoCapture(0)
while True:
ret, frame = cap.read()
if not ret: break
gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
b = np.mean(gray)
if b < 80:
led.rgb = (255,255,0)
display.text = "DARK"
elif b < 170:
led.rgb = (0,128,0)
display.text = "NORMAL"
else:
led.turn_off()
display.text = "BRIGHT"
cv2.imshow("Cam", frame)
if cv2.waitKey(1) == 27: break
움직임 감지 원리
연속 두 프레임을 비교해서 차이가 큰 부분 = 움직임!
cv2.absdiff()로 두 프레임 차이 → np.mean()으로 평균 → 임계값 이상
이면 MOTION!
