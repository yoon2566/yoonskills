3 차시 · 바이브코딩 + 개발환경
바이브코딩이란무엇인가?
코드를 몰라도 AI에게 말로 설명하면 코드가 완성되는 새로운 코딩 방법
바이브코딩 = AI + 자연어 프로그래밍
바이브코딩(Vibe Coding)은 AI에게 "이런 프로그램 만들어줘"라고 자연어
연어(일상 말)로 설명하면, AI가 코드를 작성해주는 프로그래밍 방식입니
니다.
기존 코딩은 파이썬 문법을 완벽히 알아야 했지만, 바이브코딩에서는 "
내가 원하는 것"을 정확하게 설명하는 능력이 핵심입니다.
코딩 실력보다 중요한 것:
• 문제를 명확하게 정의하는 능력
• AI에게 구체적으로 설명하는 능력 (프롬프트 작성)
• AI가 만든 코드를 읽고 이해하는 능력
• 오류가 생겼을 때 AI에게 잘 물어보는 능력

좋은 프롬프트 작성법 — AI에게 잘 부탁하기
같은 AI라도 프롬프트에 따라 결과가 완전히 달라집니다. 핵심 원칙 5가지를 배워봅시다
프롬프트 비교 — 나쁜 예 vs 좋은 예
상황
 나쁜 프롬프트
 좋은 프롬프트 차이 포인트
LED 제어 LED 켜줘 파이모디의 LED 를 빨간색으로 3초 켜고 2초 끄기를 반복하는 파이썬 코드 만들어줘 색상·시간·반복 구체적
센서 활용 센서 코드 만들어 파이모디 빛 센서 값이 300 이하이면 LED 를 흰색으로 켜는 코드 센서 종류·조건값 명시
오류 수정 안 돼 고쳐줘 이 코드 실행하면 'M od uleN otFound Error' 오류 발생. 오류 메시지: [붙여넣기] 오류 메시지 포함
기능 추가 버튼도 추가해 위 코드에 파이모디 버튼을 추가해서, 버튼 누르면 LED 색이 바뀌게 해줘 동작 결과까지 설명
프롬프트 5원칙
구체적으로 맥락 제공 단계적 요청 예시 포함 오류시 복붙
프롬프트 = AI에게 보내는 주문서입니다. 주문서가 정확할수록 원하는 결과가 나옵니다. 처음부터 완벽할 필요 없이, AI 답변을 보고 "이 부분을 바
꿔줘"라고 추가 요청하면 됩니다. 대화하듯 점점 완성해 나가는 것이 바이브코딩의 핵심입니다!

python --version
→ Python 3.8.x10 가 나오면 성공!
