01PyMODI+ 라이브러리란?
Python으로 MODI Plus 모듈을 제어하는 공식 라이브러리
라이브러리 개요
공식 저장소
github.com/LUXROBO/pymodi-plus

(권장: Python 3.8)

· BLE (블루투스) - 무선

01기본 사용법 – MODIPlus 객체 생성
bundle을 만들고 모듈에 접근하는 공통 패턴
● main.py
# 1) 라이브러리 불러오기
import modi_plus
import time
# 2) MODIPlus 객체 생성 (= bundle)
# Network 모듈을 USB로 연결한 상태여야 함
bundle = modi_plus.MODIPlus()
# 3) 연결된 모듈 확인
print(bundle.modules)
# 4) 모듈별 리스트 접근
print(bundle.leds) # LED 모듈 리스트
print(bundle.dials) # Dial 모듈 리스트
print(bundle.speakers) # Speaker 모듈 리스트
# 5) 첫 번째 모듈 변수에 저장 (n번째는 [n-1])
led = bundle.leds[0]
dial = bundle.dials[0]
# 6) 모듈 제어 및 값 읽기
led.rgb = (255, 0, 0) # 빨간색 LED
print(dial.turn) # 다이얼 각도 출력
연결 방식 2가지
● connection.py
# 1) USB 시리얼 (기본값)
bundle = modi_plus.MODIPlus(
connection_type="serialport")
# 2) BLE 블루투스 (무선)
bundle = modi_plus.MODIPlus(
conn_type="ble",
network_uuid="XXXXXXXX")
꼭 기억하세요
• Network 모듈이 USB 연결 필수
• n번째 모듈 접근은 [n-1] 사용
• 하드웨어는 time.sleep()로 딜레이
• 값 읽기 전 최소 1초 대기 권장
연결 안 될 때?
1. USB 케이블 다시 꽂기
2. Network 모듈 펌웨어 확인
3. python -m modi_plus --inspect

속성 / 메서드
 설명
 범위 / 반환

 True / False

 현재 눌려있는지

import modi_plus
import time
bundle = modi_plus.MODIPlus()

print("토글 상태 전환")

02Dial 모듈 – 다이얼
손잡이 회전 각도와 속도 측정
주요 속성
속성 / 메서드
 설명
 범위 / 반환
dial.turn
 현재 다이얼 각도
 0 ~ 100
dial.speed
 다이얼 회전 속도
 -100 ~ 100
활용 팁
• dial.turn 값을 LED 밝기, 모터 속도에
직접 연결해 아날로그 조절기로 활용
• dial.speed 는 양수=시계방향 /
음수=반시계방향
사용 예제
● dial_example.py
import modi_plus
import time
bundle = modi_plus.MODIPlus()
dial = bundle.dials[0]
led = bundle.leds[0]
# 다이얼 현재 값 출력
print("각도 :", dial.turn)
print("속도 :", dial.speed)
# 다이얼로 LED 밝기 조절 (응용)
while True:
value = dial.turn
# 0~100을 0~255로 변환
brightness = int(value * 2.55)
led.rgb = (brightness,
brightness,
brightness)
time.sleep(0.1)

02ToF 모듈 – 거리센서
레이저(적외선)로 물체까지의 거리를 측정
주요 속성
속성 / 메서드
 설명
 범위 / 반환
tof.distance
 물체까지 거리 (cm)
 0 ~ 100
ToF (Time of Flight) 원리
적외선을 쏘고 반사되어 돌아올 때까지
걸린 시간으로 거리를 계산합니다.
주의사항
• 거리는 0~100 cm 범위만 측정
• 투명/반사가 심한 표면에서는 부정확
• 태양광 강한 곳에서는 오차 증가
사용 예제
● tof_example.py
import modi_plus
import time
bundle = modi_plus.MODIPlus()
tof = bundle.tofs[0]
time.sleep(1)
# 현재 거리 읽기
distance = tof.distance
print(f"거리: {distance} cm")
# 가까워지면 경고
while True:
d = tof.distance
if d < 10:
print("너무 가까워요!")
elif d < 30:
print("주의하세요")
else:
print("안전 거리")
time.sleep(0.3)

주요 속성
속성 / 메서드
 설명
 범위 / 반환

 -100 ~ 100

 Y축 위치
 -100 ~ 100

 방향 문자열

'up' 위로 밀었을 때

사용 예제
● joystick_example.py
import modi_plus
import time
bundle = modi_plus.MODIPlus()
joystick = bundle.joysticks[0]
# X·Y 좌표값 출력
print(joystick.x)
print(joystick.y)
# 방향으로 LED 색상 제어
led = bundle.leds[0]
while True:
d = joystick.direction
if d == "up":
led.rgb = (0, 255, 0) # 초록
elif d == "down":
led.rgb = (0, 0, 255) # 파랑
elif d == "left":
led.rgb = (255, 165, 0) # 주황
elif d == "right":
led.rgb = (255, 0, 0) # 빨강
else:
led.turn_off()
time.sleep(0.1)
