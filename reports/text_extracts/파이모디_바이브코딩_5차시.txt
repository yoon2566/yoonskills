5 차시 · 파이썬 기초 ②
조건문 if · elif · else — 상황에 따라 다르게
조건이 참이면 실행, 거짓이면 건너뛰는 if 문을 배웁니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 01
if 문 구조
# 기본 if 문
score = 85
if score >= 60:
print("합격!") # 들여쓰기 4칸 필수!
# if / elif / else
score = 75
if score >= 90:
print("A등급")
elif score >= 80:
print("B등급")
elif score >= 70:
print("C등급")
else:
print("F등급")
# 출력: C등급
핵심 정리
키워드 역할 개수
if 첫 번째 조건 검사 1개 (필수)
elif 추가 조건 검사 0개 이상
else 모든 조건이 False 일 때 0~ 1 개
주의사항:
• 들여쓰기(indent) 4칸은 필수! 맞지 않으면 IndentationError
• if 다음에 콜론(:) 꼭 붙이기
• elif는 여러 개 가능, else는 최대 1개
• 위에서부터 순서대로 검사 → 첫 번째 True에서 실행
※ "=" 는 대입, "==" 는 비교. if score = 90: 은 오류! if score == 90: 이 맞습니다.

딕셔너리 — key:value 쌍으로 저장
리스트는 번호로, 딕셔너리는 이름(key)으로 값에 접근합니다
C odeW ithCathy AI 바이브코딩 × 파이모디 플러스 07
딕셔너리 기본
student = {
"name": "김철수",
"age": 17,
"city": "서울"
}
print(student["name"]) # 김철수
student["grade"] = "A" # 추가
del student["city"] # 삭제
# for문으로 순회
for k, v in student.items():
print(f" {k}: {v}")
딕셔너리 메서드

d el d ["key"] 삭제 d el d ["ag e"]
.keys() 모든 key d .keys()
.values() 모든 value d .values()
.item s() key - value 쌍 d .item s()
