Display 주요 명령어
명령어 설명 예시
.text = "..." 텍스트 출력 (한 줄) d isp lay.text = "H ello!"
.reset() 화면 전체 지우기 d isp lay.reset ()

센서값 실시간 Display — 온도계 만들기
환경 센서의 온도·습도를 Display에 실시간으로 표시합니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 03
실시간 표시 원리
센서값을 실시간으로 보려면:
① while True 루프 안에서
② 센서값을 변수에 읽고
③ f-string으로 Display에 출력
④ time.sleep()으로 갱신 주기 설정
이 패턴은 모든 센서 모니터링의 기본입니다!
온도 + LED 연동 코드
import modi_plus, time
bundle = modi_plus.MODIPlus()
env = bundle.envs[0]
display = bundle.displays[0]
led = bundle.leds[0]
while True:
temp = env.temperature
humi = env.humidity
display.text = f"T:{temp:.1f}C"
if temp > 30:
led.rgb = (255, 0, 0)
elif temp > 20:
led.rgb = (0, 255, 0)
else:
led.rgb = (0, 0, 255)
time.sleep(1)
온도 구간별 LED 매핑
온도 범위 상태 LED 색 RGB
30 °C 초과 더움
 빨강 (255, 0, 0)
20~ 30 °C 적정
 초록 (0, 255, 0)
20 °C 이하 추움
 파랑 (0, 0, 255)

9 차시 · D I S P L A Y 활용
Dial 모듈 — 다이얼로 값 조절하기
다이얼 손잡이를 돌려 LED 밝기나 색상을 조절하고 Display에 표시합니다
C odeWithCathy AI 바이브코딩 × 파이모디 플러스 05
Dial 모듈 속성
속성 설명 범위 코드
turn 다이얼 회전값 0~ 100 d ial.turn
sp eed 회전 속도 가변 d ial.sp eed
다이얼 → LED 밝기 조절
import modi_plus, time
bundle = modi_plus.MODIPlus()
dial = bundle.dials[0]
led = bundle.leds[0]
display = bundle.displays[0]
while True:
val = dial.turn # 0~100
brightness = int(val * 2.55)
led.rgb = (brightness, brightness, brightness)
display.text = f"B:{val:.0f}%"
time.sleep(0.1)
활용 아이디어
• 다이얼로 LED 밝기 조절 (0~100% → 0~255)
• 다이얼로 LED 색상 선택 (0~33: 빨강, 34~66: 초록, 67~100: 파랑)
• 다이얼 + Display로 볼륨 게이지 표시
• 다이얼 + 온도 센서로 목표 온도 설정 알림

import modi_plus, time
bundle = modi_plus.MODIPlus()
dial = bundle.dials[0]
led = bundle.leds[0]
display = bundle.displays[0]

val = dial.turn

led.rgb = (255, 0, 0)
display.text = f"RED {val:.0f}%"
elif val < 66:
led.rgb = (0, 255, 0)
display.text = f"GREEN {val:.0f}%"
