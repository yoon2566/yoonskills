설계 3단계
단계 활동 산출물 도구
1. 매핑표 설계 센서→조건→출력 매핑 정리 우선순위 매핑표 워크시트
2. 바이브코딩 매핑표를 AI 에게 전달, 코드 생성 파이썬 코드 C hatG PT / C laud e
3. 테스트·수정 코드 실행, 오류 수정, 기능 추가 완성된 프로토타입 VS C od e + 파이모디
예시: 헨젤과 그레텔 — 숲속 안전 시스템
순위 조건 (센서) 출력 (LED /D isplay/Speaker) 의미
1 소리> 70 A N D 빛< 20 LED 빨강 깜빡 + "D A N GER!" + 경보음 야간에 큰 소리 = 위험
2 ToF < 30cm LED 노랑 + "O BS TA C LE!" 장애물 접근 경고
3 빛 < 20 LED 흰색(손전등) + "D A RK" 어두움 → 자동 조명
기본 그 외 LED 초록 + "S A FE" 안전 상태

바이브코딩 프롬프트 작성법
바이브코딩 프롬프트
"파이모디 플러스로 '헨젤과 그레텔 숲속 안전 시스템'을 만들어줘. pymodi-plus 라이브러리 사용.
입력: 환경 센서(빛/소리) + ToF(거리)
출력: LED + Display + Speaker
조건:
1순위: 소리>70 AND 빛<20 → LED 빨강 깜빡 + Display 'DANGER!' + 스피커 경보
2순위: ToF<30 → LED 노랑 + Display 'OBSTACLE!'
3순위: 빛<20 → LED 흰색 + Display 'DARK'
기본: LED 초록 + Display 'SAFE'
while True에서 0.5초마다 체크. blink 함수 분리해줘. 주석 한국어로 달아줘."
프롬프트 작성 핵심 원칙
원칙 설명 예시
라이브러리 명시 어떤 라이브러리를 사용할지 "p ym od i- p lus 라이브러리 사용"
입출력 모듈 명시 사용할 센서와 출력 장치 "환경 센서 + ToF + LED + D isp lay"
조건을 표로 정리 매핑표 내용을 그대로 전달 "1순위: 조건 → 동작"
주석 요청 코드 이해를 위해 주석 요청 "주석 한국어로 달아줘"
함수 분리 요청 반복 코드를 함수로 "b link 함수 분리해줘"
